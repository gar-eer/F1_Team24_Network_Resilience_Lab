Inside the experiment Architecture, metric definitions & limitations
Python upload client→Disruption proxy
shared bandwidth · delay · outages→Upload origin
atomic commits · SHA-256

The browser controls the lab. The Python client sends the selected bytes over real localhost HTTP sockets through the proxy. Strategies run sequentially with a fresh origin and scenario clock for every trial. The initial browser-to-lab file selection upload is outside the measured experiment.

Delay is a one-way wait before forwarding each HTTP request; it is not an RTT guarantee. Throughput samples measure proxy-forwarded body bytes. Transport overhead, genuine packet loss and TCP retransmissions are unavailable. Partial data is removed at the end of every trial; results are kept in memory for this session (10 experiments).
